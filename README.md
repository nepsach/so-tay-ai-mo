## Cấu trúc

Trang làm bằng Astro Starlight. Bài viết ở `src/content/docs/`, mỗi thư mục là một mục:
`lam-quen` (Làm quen từ đầu) · `cach-lam` (Cách làm từng việc) · `ung-dung` (Tìm hiểu từng ứng dụng) · `hieu-vi-sao` (Hiểu vì sao AI làm vậy) · `hoi-dap` · `cap-nhat` · `gop-y`.

Chạy trên máy: `npm install` rồi `npm run dev`. Đẩy lên nhánh `main` thì trang tự đăng lại.
